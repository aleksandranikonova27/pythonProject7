# Сайт-визитка - проект Web

Сайт представляет собой визитку ведущего мероприятий.

## Функционал

Незарегистрированные пользователи могут:

- Просматривать содержимое сайта (фотографии, информацию о ведущем на главной странице)

Зарегистрированные пользователи являются администраторами сайта, которых назначает человек уже имеющий права. Они имею доступ к админке, где могут:

- Загружать фотографии на разделы сайта
- Редактировать информацию о фотографиях(название, описание)
- Удалять фотографии
- Просматривать заявки
- Создавать новые типы мероприятий, после чего будут создаваться новые разделы с фотографиями
- Зарегистрировать еще администраторов или удалить их

## Содержимое архива

- readme.md - этот файл
- requirements.txt - список подключаемых модулей
- main.py - главный запускаемый файл программы
- data - каталог с файлами описания классов orm-моделей
- db - каталог с базой данных visitka.db, которая содержит таблицы:
  - admins - зарегистрированные пользователи (админы)
  - media - загруженные фотографии
  - orders - заявки на проведение мероприятий
  - type_of_events - мероприятия
- forms - каталог с файлами описания классов форм
- static - каталог со статическим контентом:
  - img - загруженные фотографии
  - thumb - миниатюры загруженных фотографий
- templates - каталог с шаблонами html

## Сборка и запуск программы

Перед запуском программы необходимо установить модули, перечисленные в файле requirements.txt.

Запускать нужно файл **main.py**. 

Затем в браузере перейти по адресу: http://127.0.0.1:8080
